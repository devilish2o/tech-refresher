# Lab: MATLAB refresher

## Goal

Refresh MATLAB fundamentals and practise reading, validating and extending a small analytical script.

## Exercises

1. Create vectors, matrices and tables; distinguish matrix operations from element-wise operations.
2. Import a small synthetic CSV and inspect missing or invalid values.
3. Write a function with input validation and useful error messages.
4. Plot a time series with labels, legend and units.
5. Compare a loop-based calculation with a vectorised implementation.
6. Add a simple test or assertion to verify expected output.

## Self-check

Can you explain array dimensions, indexing, table versus matrix use, function scope and how you would validate imported data?
